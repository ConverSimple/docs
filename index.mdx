ConverSimple provides the browser and phone audio path for conversational applications. Build an agent in the dashboard, connect your tools and knowledge, or keep your existing concierge and use ConverSimple for speech input and output.

## What do you want to build?

| Goal | Start here | Who supplies the answer? |
| --- | --- | --- |
| Add speech to a signed-in SaaS concierge and its existing chat UI | [Existing SaaS concierge](/use-cases/existing-saas-concierge) | Your HTTPS reply hook |
| Answer questions on a website | [Website support](/use-cases/website-support) | A ConverSimple agent with instructions, knowledge, and tools |
| Capture and qualify website leads | [Lead capture](/use-cases/lead-capture) | A ConverSimple agent and your CRM or HTTP tool |
| Handle an after-hours phone line | [Phone receptionist](/use-cases/phone-receptionist) | A ConverSimple agent over Twilio |
| Run your own Python tool handlers | [Python SDK tools](/guides/python-sdk-tools) | Your Python service returns tool results to the agent |

New to the platform? [Create your first agent](/start/create-an-agent), then [choose a deployment path](/start/choose-a-path).
